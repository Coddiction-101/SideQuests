## 🎨 Design Fundamentals {#fundamentals}

### **1. The 7 Core Elements of Design**

#### **1.1 Line**
**What:** Basic mark connecting two points

**Types:**
- Horizontal → Calmness, stability
- Vertical → Strength, power
- Diagonal → Movement, action
- Curved → Elegance, flow
- Zigzag → Energy, chaos

**Uses:**
- Separate sections
- Guide eye movement
- Create texture/patterns
- Draw emphasis

**Practice:**
- Create 10 logos using only lines
- Design a poster with line variations

---

#### **1.2 Shape**
**What:** Enclosed area defined by lines/colors

**Types:**
- **Geometric:** Circle, square, triangle (modern, professional)
- **Organic:** Irregular, natural (friendly, creative)
- **Abstract:** Simplified recognizable forms

**Meanings:**
- Circle → Unity, completeness
- Square → Stability, trust
- Triangle → Direction, energy

**Practice:**
- Logo design using basic shapes
- Pattern creation with overlapping shapes

---

#### **1.3 Color**
**What:** Most powerful design element

**Color Theory Basics:**

**Primary Colors:**
- Red, Blue, Yellow

**Secondary Colors:**
- Orange (Red + Yellow)
- Green (Blue + Yellow)
- Purple (Red + Blue)

**Color Schemes:**
```
Monochromatic: One color + shades/tints
Analogous: Adjacent colors on wheel (Blue, Blue-Green, Green)
Complementary: Opposite colors (Red ↔ Green)
Triadic: Three evenly spaced colors
Split-Complementary: Base + two adjacent to complement
```

**Color Psychology:**
- 🔴 Red → Energy, passion, urgency
- 🔵 Blue → Trust, calm, professional
- 🟢 Green → Nature, growth, health
- 🟡 Yellow → Happiness, optimism, caution
- 🟣 Purple → Luxury, creativity, wisdom
- 🟠 Orange → Enthusiasm, confidence
- ⚫ Black → Elegance, power, mystery
- ⚪ White → Purity, simplicity, cleanliness

**60-30-10 Rule:**
```
60% - Dominant color (background)
30% - Secondary color (main elements)
10% - Accent color (call-to-action, highlights)
```

**Practice:**
- Create 5 color palettes for different moods
- Redesign a website with different color schemes

**Tools:**
- [Coolors.co](https://coolors.co/) - Color palette generator
- [Adobe Color](https://color.adobe.com/) - Color wheel
- [Paletton](https://paletton.com/) - Color scheme designer

#### **1.4 Typography**
**What:** Art of arranging text

**Font Categories:**

**1. Serif:**
- Has "feet" on letters
- Traditional, trustworthy, formal
- Examples: Times New Roman, Georgia, Playfair Display
- Use: Books, newspapers, formal documents

**2. Sans-Serif:**
- Clean, no decorations
- Modern, minimal, approachable
- Examples: Helvetica, Arial, Roboto, Futura
- Use: Websites, apps, modern brands

**3. Script:**
- Handwritten style
- Elegant, personal, creative
- Examples: Pacifico, Dancing Script, Allura
- Use: Invitations, luxury brands, logos

**4. Display/Decorative:**
- Unique, attention-grabbing
- Specific purpose, not for body text
- Examples: Impact, Bebas Neue
- Use: Headings, posters, logos

**5. Monospace:**
- Fixed-width characters
- Technical, coding
- Examples: Courier, Consolas
- Use: Code snippets, technical docs

**Typography Terms:**
```
Kerning: Space between two specific letters
Tracking: Space between all letters
Leading: Space between lines (line height)
Hierarchy: Size/weight differences for importance
Alignment: Left, Right, Center, Justified
```

**Typography Rules:**
- ✅ Use max 2-3 fonts per design
- ✅ Pair serif with sans-serif (contrast)
- ✅ Ensure readability (size, contrast, spacing)
- ✅ Hierarchy: Title > Subtitle > Body
- ❌ Never use Comic Sans (professional work)
- ❌ Don't stretch/distort fonts

**Practice:**
- Create typographic poster (text only)
- Design business card with type hierarchy

**Free Fonts:**
- [Google Fonts](https://fonts.google.com/)
- [Font Squirrel](https://www.fontsquirrel.com/)
- [DaFont](https://www.dafont.com/)
- [1001 Fonts](https://www.1001fonts.com/)

#### **1.5 Texture**
**What:** Surface quality (how it looks/feels)

**Types:**
- Physical: Actual tactile (embossing, paper grain)
- Visual: Illusion of texture (digital patterns)

**Uses:**
- Add depth and interest
- Create contrast
- Evoke emotions (rough = rugged, smooth = elegant)

**Practice:**
- Add textures to flat designs
- Create vintage/grunge effects

**Resources:**
- [Subtle Patterns](https://www.toptal.com/designers/subtlepatterns/)
- [Textures.com](https://www.textures.com/)

---

#### **1.6 Space (Whitespace)**
**What:** Empty areas around/between elements

**Importance:**
- Improves readability
- Creates focus
- Prevents clutter
- Suggests elegance

**Types:**
- Macro: Large spaces (margins, padding)
- Micro: Small spaces (letter spacing, line height)

**Practice:**
- Redesign a cluttered flyer with proper spacing
- Create minimalist poster using whitespace

---

#### **1.7 Form (3D Shape)**
**What:** Three-dimensional objects

**Types:**
- Geometric: Spheres, cubes, pyramids
- Organic: Natural forms
- Abstract: Stylized forms

**Uses:**
- Product design
- 3D illustrations
- Add depth to 2D designs

### **2. The 6 Principles of Design**

#### **2.1 Balance**
**What:** Visual weight distribution

**Types:**

**Symmetrical:**
- Mirrored elements
- Formal, stable, traditional
- Example: Wedding invitations

**Asymmetrical:**
- Unequal but balanced
- Dynamic, modern, interesting
- Example: Magazine layouts

**Radial:**
- Elements radiate from center
- Example: Circular logos

**Practice:**
- Create symmetrical logo
- Design asymmetrical poster

---

#### **2.2 Contrast**
**What:** Difference between elements

**Types:**
- Color contrast (light vs dark)
- Size contrast (big vs small)
- Shape contrast (geometric vs organic)
- Texture contrast (smooth vs rough)

**Why:**
- Create visual interest
- Establish hierarchy
- Guide attention
- Improve readability

**Practice:**
- Black & white poster (maximum contrast)
- Play with size contrasts

---

#### **2.3 Emphasis (Focal Point)**
**What:** Main area of attention

**How to Create:**
- Make it bigger
- Use contrasting color
- Isolate with space
- Use different shape/texture

**Practice:**
- Design ad with clear focal point
- Create hierarchy in magazine spread

---

#### **2.4 Movement**
**What:** Path eye follows through design

**How to Create:**
- Lines leading to focal point
- Repeated elements (eye follows pattern)
- Gradual size/color changes
- Implied motion (dynamic shapes)

**Practice:**
- Create poster that guides eye top to bottom
- Design with diagonal movement

---

#### **2.5 Proportion/Scale**
**What:** Relative size of elements

**Golden Ratio:**
- 1:1.618 (found in nature)
- Aesthetically pleasing proportions

**Rule of Thirds:**
- Divide canvas into 3x3 grid
- Place important elements on intersections

**Practice:**
- Design using golden ratio
- Apply rule of thirds to layouts

---

#### **2.6 Unity (Harmony)**
**What:** Elements work together cohesively

**How to Achieve:**
- Consistent color scheme
- Similar shapes/styles
- Repeated patterns
- Aligned elements

**Practice:**
- Create brand identity (logo + collateral)
- Design multi-page document with unity

---

### **3. Additional Design Concepts**

#### **3.1 Hierarchy**
**Visual ranking of elements by importance**

**Methods:**
- Size (bigger = more important)
- Color (bright/bold = attention)
- Position (top/center = priority)
- Contrast (different = noticeable)

**Example:**
```
Headline (48px, Bold, Dark)
Subheadline (24px, Regular, Gray)
Body Text (16px, Light, Light Gray)
```

---

#### **3.2 Grid Systems**
**Framework for organizing content**

**Types:**
- **Manuscript Grid:** Single column (books, essays)
- **Column Grid:** Multiple columns (magazines, newspapers)
- **Modular Grid:** Columns + rows (web layouts)
- **Hierarchical Grid:** Flexible, intuitive (editorial)

**Benefits:**
- Consistency
- Alignment
- Faster design process
- Professional look

**Practice:**
- Design magazine spread with 3-column grid
- Create website mockup with 12-column grid

---

#### **3.3 Composition**
**Arrangement of visual elements**

**Common Compositions:**
- **Rule of Thirds:** Place subject on grid intersections
- **Centered:** Formal, balanced
- **Diagonal:** Dynamic, energetic
- **Frame within Frame:** Draw focus
- **Leading Lines:** Guide eye to subject
