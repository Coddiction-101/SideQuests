## 🎨 Building Portfolio {#portfolio}

### **Portfolio Essentials**

**What to Include:**
- 8-12 best projects (quality > quantity)
- Variety (show range but stay cohesive)
- range but stay cohesive)
- Case studies (process, not just final result)
- About page (who you are, what you do)
- Contact information

**What NOT to Include:**
- ❌ Beginner work (even if you're proud)
- ❌ Too many projects (overwhelming)
- ❌ Work you don't want to do more of
- ❌ Low-quality images
- ❌ Unfinished projects

---

### **Portfolio Platforms**

**Free Options:**
1. **Behance** (Adobe)
   - Industry-standard
   - Good SEO
   - Free hosting

2. **Dribbble** (Free + Pro)
   - Designer community
   - Shot-based (not full projects)

3. **Cargo Collective** (Free tier)
   - Clean templates
   - Portfolio-specific

**Custom Website:**
4. **Wix/Squarespace** ($16-$30/month)
   - Drag-and-drop
   - Professional templates
   - Custom domain

5. **WordPress** (Free + hosting $5-20/month)
   - Full control
   - Requires more setup

6. **Webflow** (Free + paid plans)
   - Design-focused
   - No coding needed
   - Professional results

**Recommended:**
```
Beginner: Behance (free, easy)
Serious Freelancer: Custom website (Squarespace/Webflow)
UI/UX Designer: Personal site + Dribbble
```

### **Project Presentation Tips**

**Case Study Structure:**
```
1. Project Title + Client
2. Brief/Problem Statement
3. Research/Discovery
4. Design Process (sketches, iterations)
5. Final Solution (mockups, photos)
6. Results/Impact (if available)
```

**Image Quality:**
- High resolution (at least 1920px wide)
- Clean mockups (use Smartmockups, Placeit)
- Consistent presentation style
- Show context (how design is used)

**Mockup Resources:**
- [Smartmockups](https://smartmockups.com/)
- [Placeit](https://placeit.net/)
- [Mockup World](https://www.mockupworld.co/)
- [Freepik Mockups](https://www.freepik.com/mockups)

### **Creating Portfolio Projects (No Clients Yet)**

**Self-Initiated Projects:**
1. **Rebrand existing companies**
   - Choose outdated brands
   - Redesign logo, identity, website

2. **Fictional businesses**
   - Create café branding
   - Design app for problem you have
   - Invent startup identity

3. **Daily challenges**
   - 30 days of logos
   - UI daily challenge
   - Poster-a-day

4. **Spec work for causes**
   - Non-profit rebrand
   - Social campaign design
   - Community project

**Portfolio Boosters:**
- Personal branding (design your own identity)
- Passion projects (design for hobbies)
- Concept work (dream client/project)
- Free work (1-2 clients for testimonials + case studies)
