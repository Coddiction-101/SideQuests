# GRAPHIC DESIGN QUICK REFERENCE

## 7 Elements
1. Line - Direction, movement
2. Shape - Geometric vs Organic
3. Color - 60-30-10 rule, psychology
4. Typography - Max 2-3 fonts
5. Texture - Visual interest
6. Space - Whitespace = elegance
7. Form - 3D depth

## 6 Principles
1. Balance - Symmetrical/Asymmetrical
2. Contrast - Create emphasis
3. Emphasis - Focal point
4. Movement - Eye flow
5. Proportion - Size relationships
6. Unity - Cohesive whole

## Color Theory
Primary: Red, Blue, Yellow
Secondary: Orange, Green, Purple
Schemes: Monochromatic, Analogous, Complementary, Triadic

## Typography
Serif: Traditional, formal
Sans-Serif: Modern, clean
Script: Elegant, personal
Display: Unique, headings
Monospace: Technical, code

## Design Process
1. Brief/Discovery
2. Research
3. Sketching/Ideation
4. Digital concepts (2-3)
5. Feedback/Revisions
6. Final delivery

## File Formats
PNG: Transparency, web
JPG: Photos, small size
SVG: Scalable vector
PDF: Print-ready
PSD/AI: Source files

## Print Specs
Resolution: 300 DPI
Color Mode: CMYK
Bleed: 3mm
Safe Zone: 5mm inside

## Standard Sizes
Business Card: 3.5" × 2"
Letter: 8.5" × 11"
A4: 210mm × 297mm
Instagram Post: 1080×1080px
Instagram Story: 1080×1920px

## Software
Raster: Photoshop, GIMP
Vector: Illustrator, Inkscape
Layout: InDesign
UI: Figma, Adobe XD
Free: Canva, Figma

## Freelance Pricing (Beginner)
Logo: $100-300
Social Media Post: $15-30
Website Mockup: $300-800
Branding Package: $500-1500

## Portfolio Must-Haves
- 8-12 best projects
- Case studies (process)
- Variety + cohesion
- About page
- Contact info
- High-res mockups

## Client Process
1. Discovery call
2. Send proposal/quote
3. 50% deposit
4. Create concepts
5. Present + revisions
6. Final payment
7. Deliver files

## Growth Path
Month 1-2: Learn fundamentals + tools
Month 3-4: Build portfolio (10+ pieces)
Month 5-6: First clients (Fiverr/local)
Month 7-12: Raise rates, specialize
Year 2+: Premium pricing, passive income

## Red Flags (Avoid)
❌ "Work for exposure"
❌ "Do it cheap, more work later"
❌ No contract
❌ Unlimited revisions
❌ Scope creep

## Success Formula
Skill × Portfolio × Marketing = Clients
